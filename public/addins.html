“citemyshi

Cite while you write

Insert citations and footnotes from your citemyshi project straight into Word or Google Docs. Click Update citations any time and every footnote is renumbered properly — Ibid, (n 3), short forms and IEEE numbering — then add your bibliography in one click.

First, get your project’s connection code
  1. On citemyshi.web.app, sign in (bottom-left) so your project can be shared securely.
  2. Open the project’s menu (⋯ next to its name in the sidebar) → Use in Word / Google Docs.
  3. Copy the 12-character code. Anyone with it can read that one project’s sources, so treat it like a private link.

Microsoft Word

Download the add-in file (manifest.xml)
  1. Word on the web or Windows (Microsoft 365): Home or Insert tab → Add-ins → More add-ins → My Add-ins → Upload My Add-in → choose the file you downloaded.
  2. Word on Mac: put the file in ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/ (create the wef folder if it isn’t there), then restart Word and look under Insert → Add-ins → My Add-ins.
  3. Open the References tab → Citations. Enter your code once — the document remembers it.
  4. Click where the citation goes, pick the source, add a page or section if needed, and click Insert. For footnote styles (AGLC, Chicago, OSCOLA) a footnote is created for you.

Footnotes need Word for Microsoft 365, Word 2021 or Word on the web. Older Word versions can still insert in-text citations and bibliographies.

Google Docs

  1. Open your essay in Google Docs → Extensions → Apps Script.
  2. Replace everything in Code.gs with the code below and save.
  3. Click + next to Files → HTML, name it Sidebar (exactly), paste the second block below and save.
  4. Reload your document. A citemyshi menu appears → Open citemyshi. Google asks you to allow it once (it can only access this document).
  5. Enter your code. For footnote styles, add a footnote first (Ctrl/⌘ + Alt + F) and click Insert with your cursor inside it.

Any other editor

In your project, click Footnotes (or Citation order), list your citations in essay order, and copy the finished footnotes — Ibid and short forms included — into Pages, LibreOffice, LaTeX or anything else.
